## 3. CTC Forced-Alignment Kernel (Shared CTC kernel performs forced alignment, per design decision Shared CTC kernel in alignment/ctc.py and Audio decoding inside backends, not in the kernel)

- [x] 3.1 Create `src/talking_parrot/alignment/ctc.py` with `ctc_align(emissions: torch.Tensor, dictionary: dict[str, int], transcript_tokens: list[str], blank_id: int, frame_rate_hz: float, *, segment_offset_ms: int) -> list[AlignedToken]`. Lazy-import torch at the top of the module guarded by `try/except ImportError` so that constructing other modules does not require torch. Implement: empty `transcript_tokens` short-circuits to `[]`; build `tokens: list[int]` via `dictionary.get(tok)` with `None` for missing entries; expand `emissions` with one extra "wildcard" column whose value per frame is `max(emissions[t, j!=blank_id])` so missing-from-dictionary tokens can map to it (covers: Shared CTC kernel performs forced alignment)
- [x] 3.2 Implement `_get_trellis(emission, tokens, blank_id) -> torch.Tensor` per WhisperX: `T[0,0]=0`, `T[0,j>0]=-inf`; recurrence `T[t+1, j+1] = max(T[t, j+1] + emission[t, blank_id], T[t, j] + emission[t, tokens[j]])`. Return a `(num_frames+1, num_tokens+1)` tensor on the same device as `emission`
- [x] 3.3 Implement `_backtrack(trellis, emission, tokens, blank_id) -> list[Point]` where `Point = NamedTuple("Point", token_index, time_index, score)`. Trace from `(num_frames, num_tokens)` choosing the larger of `(stay-blank, advance-token)` per step until `(0, 0)`. Emit points in chronological order
- [x] 3.4 Implement `_merge_repeats(path, transcript_tokens) -> list[Segment]` where `Segment = NamedTuple("Segment", label, start_frame, end_frame, score)`. Group consecutive points with identical `token_index`, average their scores. Skip segments whose `token_index` corresponds to the wildcard column when emitting `AlignedToken` entries
- [x] 3.5 Implement `_segments_to_tokens(segments, frame_rate_hz, segment_offset_ms) -> list[AlignedToken]`: convert each `Segment` to `AlignedToken(word=label, start_ms=segment_offset_ms + round(start_frame * 1000 / frame_rate_hz), end_ms=segment_offset_ms + round(end_frame * 1000 / frame_rate_hz), score=score)`. For tokens whose dictionary lookup failed AND wildcard score per frame is `-inf` (no usable column), emit `AlignedToken(word=tok, start_ms=float('nan'), end_ms=float('nan'), score=0.0)` placeholders before the conversion
- [x] 3.6 Implement `_interpolate_nans(tokens: list[AlignedToken]) -> list[AlignedToken]`: scan once; for each token whose `start_ms` is `NaN`, fill from the nearest preceding non-NaN token's `end_ms`; for each token whose `end_ms` is `NaN`, fill from the nearest following non-NaN token's `start_ms`. If a NaN token has no neighbour on a side, fall back to the segment endpoint (`segment_offset_ms` for missing-leading, last frame end for missing-trailing). If every token is NaN, set every `start_ms = end_ms = segment_offset_ms` and `score = 0.0`
- [x] 3.7 Create `tests/unit/alignment/test_ctc.py`: (a) empty `transcript_tokens` returns `[]`; (b) trellis recurrence on a 3-frame, 2-token toy emission tensor produces hand-verified `(num_frames+1, num_tokens+1)` shape; (c) backtrack on the same toy yields the expected `Point` sequence; (d) merge_repeats collapses `[Point(0,0,0.5), Point(0,1,0.6)]` into one `Segment` with averaged score `0.55`; (e) `_segments_to_tokens` with `frame_rate_hz=50.0, segment_offset_ms=1000` and segment `(label="a", start_frame=0, end_frame=10, score=0.9)` yields `AlignedToken("a", 1000, 1200, 0.9)` (10 frames @ 50 Hz = 200 ms); (f) interpolate scenario from spec: tokens with timings `[(100,200), (NaN,NaN), (400,500)]` → middle token becomes `(200, 400)`; (g) all-NaN fallback collapses every token to `(segment_offset_ms, segment_offset_ms, 0.0)` (covers: Empty transcript yields empty token list, NaN interpolation fills missing timestamps)
