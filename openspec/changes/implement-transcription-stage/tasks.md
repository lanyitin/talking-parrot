- [x] 5.2 Implement the TranscriptionStage cascade evaluation loop in `TranscriptionStage.process`: for each chunk, initialise `latest_result: TranscriptionResult | None = None`, `latest_metrics: dict[str, Any] = {}`; iterate `ctx.config.transcribing`; for each step call `self._evaluator.evaluate(step.condition, latest_metrics)`; on falsy break the inner loop; on truthy call `self._factory.create(step.backend).transcribe(ctx.media_info.path, chunk, step.model, step.language or ctx.config.expected_language)`, replace `latest_result`, and refresh `latest_metrics` from `result.metrics` (covers: TranscriptionStage drives a cascade across transcribing[] steps, Step 0 always runs with empty metrics, Cascade halts on falsy condition, Cascade upgrades on truthy condition, cascade decision table)

- [x] 5.4 Implement bounded-fallback exception handling in `TranscriptionStage.process`: wrap each non-step-0 backend call in `try/except Exception as exc`; on exception emit `logger.warning("transcription step %d failed: backend=%s model=%s exc=%s", idx, step.backend, step.model, type(exc).__name__)`, keep `latest_result` unchanged, and break the inner loop; do NOT wrap step 0 — step 0 exceptions propagate (covers: TranscriptionStage falls back to prior result on backend failure for steps after step 0, Step 1 backend failure preserves step 0 result, Step 0 backend failure propagates)
