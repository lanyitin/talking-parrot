使用者以繁體中文溝通，設計文件也應以繁體中文撰寫。

docs/ 目錄是一個 Obsidian Vault，所有放入此目錄的文件應使用 Obsidian Flavored Markdown 語法（wikilink、frontmatter properties、callouts 等）。

**How to apply:** 產生文件時一律加入 YAML frontmatter（title、tags、aliases），使用 `[[wikilink]]` 連結同一 Vault 的其他文件，不使用相對路徑 Markdown 連結。
